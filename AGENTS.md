# Agent instructions

Before changing upload ownership, streaming, login verification, share quota,
security flags or deployment rollback, read [docs/security-flags.md](docs/security-flags.md).
That document is the canonical flag contract and agent verification checklist.

Before changing CSP, Cloudflare scripts or font allowlists, read
[docs/csp.md](docs/csp.md) for the nonce and nginx deployment requirements.
